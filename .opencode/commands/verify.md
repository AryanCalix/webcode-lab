---
description: Jalankan typecheck, lint, unit test, dan build production
---

Jalankan verifikasi lengkap proyek WebCode Lab secara berurutan:

1. `npm run typecheck`
2. `npm run lint`
3. `npm run test`
4. `npm run build`

Jika ada langkah yang gagal, perbaiki penyebabnya lalu jalankan ulang langkah tersebut. Setelah semua lulus, laporkan ringkasan hasil setiap langkah. Jangan mengubah konfigurasi hanya agar pemeriksaan lolos.
